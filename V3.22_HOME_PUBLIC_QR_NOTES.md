# V3.22 - Home Public QR

- Added a QR code to the phone Home screen directly above the Public Display URL.
- The QR payload is exactly `TvServerInfo.url`, the same current server URL used by the Public Display QR endpoint.
- QR is generated locally with the existing ZXing dependency and shown on a white background for reliable scanning.
- Existing tap-to-copy behavior on the URL remains unchanged.
- No game logic, public/private state logic, or intro behavior was changed in this version.
