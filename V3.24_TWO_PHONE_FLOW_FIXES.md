# V3.24 – Two Phone Flow Fixes

Changes from V3.23:

- Detective session token is now a random 4-digit code (1000–9999).
- Home content is shifted slightly downward so the QR block does not crowd the artwork/text at the top.
- Detective browser map now supports pinch zoom, one-finger pan while zoomed, mouse-wheel zoom, mouse drag, and double-click fit/reset. Zoom is preserved during normal 700 ms state refreshes.
- Search / Arrest phase now has a dedicated always-visible "تحویل به جک" bar above the detective controls so the turn cannot get stuck because the handoff button is below the scrollable controls.
- Two-phone games now start in a lobby (`TWO_PHONE_LOBBY`). The game does not enter Hell immediately.
- The Detective URL initially opens a full-screen page containing only a "شروع بازی" button.
- Pressing that button starts Night 1, triggers the Hell intro, and then the existing game flow continues.
- While waiting in the lobby, the Jack phone shows "منتظر شروع بازی توسط کارآگاه" and displays both Public and Detective QR codes plus the 4-digit Detective code.
- Existing single-phone digital mode and its PIN flow are unchanged.
