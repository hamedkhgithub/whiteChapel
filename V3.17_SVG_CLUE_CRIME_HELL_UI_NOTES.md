# V3.17 changes

- Uses supplied `search.svg` geometry for clue markers on phone and public display.
- Uses supplied `target.svg` geometry for crime-scene markers on phone and public display.
- Adds independent clue color/size and crime-scene color/size controls for Phone and Public Display. Previous-night crime scenes remain gray; current-night crime scenes use the selected color.
- Adds adjustable yellow setup-square size for Phone and Public Display. The seven printed yellow police setup crossings are outlined only during `HELL_POLICE`; game placement rules are unchanged.
- Launcher/app label shortened to `White Chapel Game`.
- Splash `Initializing...` is explicitly LTR and left-aligned so punctuation stays after the English word.
- Home menu reordered into: new game with map + continue, new game without map + continue, then a full-width Settings button.
- Preserves V3.16 public calibration controls and Legacy TV/webOS compatibility work.

Source SVGs are preserved under `app/src/main/assets/markers/`.
