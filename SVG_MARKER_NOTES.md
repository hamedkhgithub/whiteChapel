# V3.14 SVG marker update

- Victim marker geometry is derived from `heart-svgrepo-com.svg`.
- Police marker geometry is derived from `police-hat-authority-svgrepo-com.svg`.
- Both phone Canvas and public browser use the new shapes.
- Fill transparency still comes from Appearance Settings; outlines stay fully opaque.
- Public browser no longer uses the Unicode heart or circular police marker.
- Alley Move Track token enlarged from 34 native board px to 56 px (public: 56x47).
- Legacy TV ES5/XHR compatibility and separate applicationId are preserved.
