# V3.19 Night / Hunting intros

- `app/src/main/assets/intro-hell.html`: complete Hell intro graphic (HTML + CSS + JS).
- `app/src/main/assets/intro-hunting.html`: complete Hunting intro graphic (HTML + CSS + JS).
- The same HTML assets are used on the Android phone (WebView) and served to the public display.
- Hell intro runs when a new digital-map game starts and when a new night starts.
- Hunting intro runs when the kill is committed and Hunting begins, including Night 3 Double Event.
- Continue Game does not start a new intro unless an intro was already in progress when the app was interrupted.
- Intro state is presentation-only; game phase/state transitions are unchanged.
