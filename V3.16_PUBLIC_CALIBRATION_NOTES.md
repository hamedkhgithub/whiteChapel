# V3.16 Public Display Calibration

Changes in this build:

- Added Public Display calibration controls in Appearance Settings:
  - X Offset: -400..+400 px
  - Y Offset: -400..+400 px
  - Overlay Scale: 75%..125%
  - Public UI Text Size: 70%..200%
- Calibration applies to public-map overlay coordinates (house-number badges, public markers, clues/crime markers, and Move Track markers) while the board image itself remains fixed.
- Added a one-tap reset for Public Display calibration.
- Removed the public-display legend/message stating that Jack's secret information is not sent to the page.
- Kept the fixed 1536x1024 WebOS canvas and Legacy-TV JavaScript compatibility from V3.15.
- Version: 3.16-public-calibration (versionCode 16).
