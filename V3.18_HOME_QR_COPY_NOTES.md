- Based on user-edited `whiteChapel-3.3SettingLegacy.zip`.
- Preserved RTL `HomeGameRow` placement: New Game on the right, Continue on the left.
- New Game title now occupies remaining button width and is right-aligned.
- `Initializing...` remains LTR but is centered below the loading bar.
