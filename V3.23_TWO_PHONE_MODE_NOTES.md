# V3.23 — Two Phone Mode

Adds a third game mode that keeps the Android phone dedicated to Jack and moves Detective interaction to a second phone browser.

## Home
- New row: Start New Game with Two Phones + Continue Game.
- Two-phone saves are stored separately from the existing single-phone digital save.
- When a two-phone save exists, Home shows two separated QR codes: Public and Detective.
- Detective URL uses a random per-game token.

## Two-phone flow
- No Jack PIN is created or requested.
- Jack phases remain on the Android phone.
- During Detective-owned phases the Android phone shows: `منتظر حرکت کارآگاه`.
- During Jack-owned phases the Detective browser shows: `منتظر حرکت جک`.
- Handoffs change the active side without physically passing the Android phone.

## Detective browser
- `/detective?k=<token>` is an interactive browser UI.
- Supports police setup, victim movement, police movement, Search, Arrest, ending a police search, and handoff back to Jack.
- The Android game remains authoritative: browser actions are validated/applied by Kotlin and saved to the same two-phone game state.
- Detective state intentionally excludes Jack hideout, current location, and Jack path.

## Existing modes
- Existing no-map and single-phone map saves/flows remain separate.
- Single-phone map mode retains its PIN flow.
